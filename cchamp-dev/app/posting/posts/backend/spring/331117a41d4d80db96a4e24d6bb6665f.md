따라서 해당 id를 넣는 공간을 만들었는데 이는 `[category]/[subCategory]/import-notion` 을 경로로 잡아 페이지를 불러올 시 `/posting/posts/[category]/[subCategory]/[notionId].md` 로 저장하게 만들었습니다.


이때 크게 사용한 기술을 3가지 입니다.

- Next API 기능 - 서버 없이 api를 만들기 위한 기술 (이를 통해 간단히 vercel를 통해 배포가 가능합니다.)
- Notion API - 등록된 워크스페이스에서 페이지를 `.md` 로 불러오는 API
- MarkdownRenderer - 불러온 `.md` 내용을 파싱하여 html로 바꿔주는 컴포넌트

## Next API


우선 기본적으로 Next에는 클라이언트단과 서버단이 존재하며 클라이언트에서는 `state`, `effect` 등을 사용할 수 있지만 api 요청 등의 중요한 통신을 할 수 없습니다. 


이를 해결하기 위해 Next에는 자체적으로 서버역할을 하는 api 기능을 지원하며 `/app/api/*/route.ts` 를 통해 정의가 가능해집니다.

<details>
<summary>/app/api/notion-import/route.ts</summary>

```typescript
// app/api/notion-import/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { getNotionPageMarkdown } from '../../lib/notion';
import { saveMarkdownFile } from '../../lib/saveMarkdownFile';

export async function POST(req: NextRequest) {
  try {
    const { notionId, category, subCategory } = await req.json();

    if(!notionId) {
      return NextResponse.json({ message: "필수 값이 부족합니다." }, { status: 400 });
    }

    const markdown = await getNotionPageMarkdown(notionId);

    if (!markdown) {
      return NextResponse.json({ message: '불러오기 실패' }, { status: 400 });
    }

    saveMarkdownFile(markdown, category, subCategory, notionId);

    return NextResponse.json({ success: true, markdown });
  } catch (error) {
    return NextResponse.json({ message: '서버 오류' }, { status: 500 });
  }
}
```


</details>

<details>
<summary>getNotionPageMarkdown</summary>

```typescript
import { Client } from "@notionhq/client";
import { NotionToMarkdown } from "notion-to-md";

const notion = new Client({
  auth: process.env.NEXT_PUBLIC_NOTION_API_KEY,
});

const n2m = new NotionToMarkdown({ notionClient: notion });

export async function getNotionPageMarkdown(pageId: string): Promise<string | null> {
  try{
    const mdBlocks = await n2m.pageToMarkdown(pageId);
    const mdString = n2m.toMarkdownString(mdBlocks);
    return typeof mdString === "string" ? mdString : mdString.parent;
  }
  catch(e){
    return null;
  }
}
```


</details>


위의 route.ts에서 `getNotionPageMarkdown` 이라는 실제로 api요청을 하는 함수를 호출하여 서버단에서 정상적으로 api요청을 하여 `.md` 코드를 받게됩니다.


### MarkdownRenderer


이때 받은 `.md` 파일을 그대로 출력하게되면


```typescript
# [제목]

--- (가로선)

``` (코드)
```


같은 것들이 위와 같이 날것으로 보이기 때문에 이를 파싱 해주어야하는데 이를 위해서 3가지의 라이브러리를 사용하였습니다.

<details>
<summary>MarkdownRenderer</summary>

```typescript
import React from "react";
import ReactMarkdown from "react-markdown";
import remarkGfm from "remark-gfm";
import rehypeHighlight from "rehype-highlight";

type Props = {
  content: string;
};

export default function MarkdownRenderer({ content }: Props) {
  return (
    <article className="prose prose-invert max-w-none">
      <ReactMarkdown
        remarkPlugins={[remarkGfm]}
        rehypePlugins={[rehypeHighlight]}
        components={{
          h1: ({ children }) => (
            <h1 className="text-3xl font-bold mt-8 mb-4">{children}</h1>
          ),
          h2: ({ children }) => (
            <h2 className="text-2xl font-semibold mt-6 mb-3">{children}</h2>
          ),
          p: ({ children }) => (
            <p className="leading-7 my-3 text-black">{children}</p>
          ),
          a: ({ href, children }) => (
            <a
              href={href}
              target="_blank"
              rel="noreferrer"
              className="text-blue-400 underline"
            >
              {children}
            </a>
          ),
          code(props) {
            const { children, className } = props;
            const isInline = !className;

            if (isInline) {
              return (
                <code className="bg-green-200 px-1 py-0.5 rounded text-sm">
                  {children}
                </code>
              );
            }

            return (
              <code className={className}>
                {children}
              </code>
            );
          },
          pre: ({ children }) => (
            <pre className="rounded-xl p-4 overflow-x-auto bg-gray-300">
              {children}
            </pre>
          ),
          img: ({ src, alt }) => (
            // 우선은 일반 img로 시작
            <img
              src={src ?? ""}
              alt={alt ?? ""}
              className="rounded-lg my-4 max-w-full"
            />
          ),
        }}
      >
        {content}
      </ReactMarkdown>
    </article>
  );
}
```


</details>

1. react-markdown - 핵심 라이브러리로 마크다운 표기를 리액트 컴포넌트로 변환해주며 XSS, 기능 또한 함께 제공해줍니다. `<ReactMarkdown> {내용} </ReactMarkdown>` 을 통해 사용이 가능합니다.
2. remark-gfm - 기본 마크다운 파서에 없는 기능을 지원해주며 `~~~` (취소선), `- [x]` (체크리스트), `| --- | --- |` (표) 등을 지원해줍니다. `<ReactMarkdown remarkPlugins={[remarkGfm]}>` 를 통해 사용 가능합니다.
3. rehype-highlight - 코드 하이라이팅 등을 제공합니다. `<ReactMarkdown rehypePlugins={[rehypeHighlight]}>` 를 통해 사용 가능합니다.
