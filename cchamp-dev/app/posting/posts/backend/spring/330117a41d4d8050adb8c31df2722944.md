### 1. 서버 준비


Docker을 활용한다 하더라도 돌릴 서버가 필요한데 이때 사용하는 서버로는 Spring를 선택하였으며 [`application.properties`](http://application.properties/) 를 적을 때에도 도커로 빌드할 경우를 상정하여 작성하게 되었다.


```xml
spring.application.name=JpaTest

server.port=${SERVER_PORT:8080}

spring.datasource.url=${SPRING_DATASOURCE_URL:jdbc:mysql://localhost:3306/JPA_TEST?serverTimezone=Asia/Seoul&characterEncoding=UTF-8}
spring.datasource.username=${SPRING_DATASOURCE_USERNAME:root}
spring.datasource.password=${SPRING_DATASOURCE_PASSWORD:1234}
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

spring.jpa.hibernate.ddl-auto=${SPRING_JPA_HIBERNATE_DDL_AUTO:update}
spring.jpa.show-sql=${SPRING_JPA_SHOW_SQL:true}
spring.jpa.properties.hibernate.format_sql=${SPRING_JPA_FORMAT_SQL:true}
```


이후 간단한 서버 설정 (CORS 문제)와 `/sample/check` 를 통한 포트 확인 기능을 넣어주었습니다.

package com.hurwan.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class WebConfig {
	
	@Bean
	public WebMvcConfigurer corsConfigurer() {
		return new WebMvcConfigurer() {
			@Override
			public void addCorsMappings(CorsRegistry registry) {
				registry.addMapping("/**")
						.allowedOrigins("https://hoppscotch.io/", "http://localhost:*")
						.allowedMethods("GET", "POST", "PUT", "DELETE")
						.allowedHeaders("*")
						.allowCredentials(true);
			}
		};
	}
}

### 도커 이미지 만들기


이제 도커를 통해 이미지를 만들어야하는데 기본적으로 미리 빌드를 해놓고 사용할 수 있지만 다른 환경에서도 사용 가능하고 빌드에 필요한 도구는 이미지에 넣지 않기 위해 **직접 빌드**하는 방식을 사용하였습니다.


```docker
# 쓰고 버리는 용도의 빌더 전용 maven 빌드 도구
FROM maven:3.9.9-eclipse-temurin-17 AS builder

WORKDIR /build

COPY pom.xml .
COPY src ./src

# ?.jar 빌드하기
RUN mvn clean package -DskipTests

# 다음 단계 밟아주기
FROM eclipse-temurin:17-jdk

WORKDIR /app

# 앞에서 빌드된 환경에서 *.jar 뽀려오기
COPY --from=builder /build/target/*jar app.jar

# `java -jar app.jar` 을 통해 서버 실행해주기
ENTRYPOINT ["java", "-jar", "app.jar"]
```


와 같은 이미지를 만들었으며 앞에서 만들어놓은 [`application.properties`](http://application.properties/) 설정에 의해 도커 이미지 실행시킬 때 환경을 함께 주어야합니다.


```docker
docker run -d `
  --name [컨테이너 이름]`
  -p [외부 포트]:[내부 포트] `
  -e SERVER_PORT=[스프링 포트(=내부포트)] `
  -e "SPRING_DATASOURCE_URL=jdbc:mysql://host.docker.internal:3306/JPA_TEST?serverTimezone=Asia/Seoul&characterEncoding=UTF-8" `
  -e SPRING_DATASOURCE_USERNAME=root `
  -e SPRING_DATASOURCE_PASSWORD=1234 `
  jpatest-app
```

### 테스트 해보기


이제 진짜 로드밸런싱이 잘 되고있는지 확인을 해보아야하는데 이를 위해서 powershell을 이용하였습니다.
(브라우저는 캐싱 때문에 확실하지 않아서)


```powershell
1..20 | ForEach-Object {
    $response = Invoke-RestMethod -Uri "http://localhost/sample/check"
    Write-Host "요청 [$_] -> 응답 포트: $($response.port)"
}
```


위의 코드는 제미나이에게 받은 코드인데 간단하게 이해해보면

- `1..20` - 파이썬의 리스트 컴프리헨션같은 기능입니다.
- `ForEach-Object` - 딱보기에도 for문입니다. 순회하면서 반복합니다.
- `Invoke-RestMethod -Uri "..."` - 요청을 하여 응답을 받습니다.
- `Write-Host` - 콘솔을 찍습니다.
- `[$_]` - 현재 순회중인 아이템을 찍습니다.
- `$($response.port)` - 누가봐도 응답 json에서의 port입니다.
