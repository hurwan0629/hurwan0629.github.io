# AOP 복습

복습하자: No
태그: AOP, BeanPostProcessor, spring
중요도: No
좋은 포인트: No
날짜: 2026년 3월 27일

스프링에서의 AOP는 스프링이 관리하는 빈 프록시(대리 객체)에 메서드를 전후에 끼워 자동으로 로직(Aspect)가 실행되게 하는 기술입니다.

AOP는 특정 메서드(Pointcut)가 특정 실행시점(Advice)에 특정 로직(Aspect)를 실행시키는 길술입니다. 이렇게 스프링이 프록시를 통해 Aspect를 끼워넣는 과정을 Weaving이라고 부릅니다.

### 핵심 원리

앞서 설명하였듯 스프링은 기본적으로 프록시 패턴을 사용합니다. 예를 들어 `주문 서비스`에서 `주문 저장` 메서드를 실행하려 할 때 Weaving를 수행하기 위해선 스프링이 저장하고있는 빈을 그대로 사용하지 않고 프록시 객체를 만들어 컨테이너에 등록하여 사용하게 됩니다.

스프링이 프록시를 만드는 방식은 2가지로 

1. JDK Dynamic Proxy - 대상이 인터페이스를 구현하고 있는 경우 대상을 구현하여 사용합니다.
2. CDLIB Proxy - 대상 클래스 자체를 상속하여 프록시를 생성하며 바이트코드를 조작하여 생성합니다. (하지만 `final` 맴버는 오버라이딩을 할 수 없어 제한이 있습니다.)

> 모두 런타임에 프록시를 빌드하는 동적 생성 방식을 사용합니다.
> 

### BeanPostProcessor

AOP에서 대표적으로 위빙 작업을 하는 것은 `AnnotationAwareAspectJProxyCreator` 이 담당하며 해당 클래스는 `BeanPostProcessor`의 구현체입니다.

`BeanPostProcessor`은 빈의 생성/초기화 전후로 빈 객체를 조작 또는 바꿔치기하는 기능을 제공합니다.

- AOP 적용 대상인지 검사
- 연결 advice 확인
- 필요에 따라 프록시 객체 생성 및 프록시 등록

등의 작업을 수행합니다.

## 사용방법 - 프레임워크

스프링 프레임워크에서의 의존성은

- `org.springframework:spring-context`
- `org.springframework:spring-aop`
- `org.aspectj:aspectjweaver`

이 존재합니다. 마지막의 `aspectjweaver` 은 `Aspect` 를 사용하기 위해 필요합니다. 이를 위해 스프링에 특정 메서드를 특정 시점에 실행하라는 `.xml` 파일의 코드를 작성해주어야합니다.

만약 `com.hurwan.controller.SampleController.*.*(..)` 에서 `com.hurwan.aspect.TimerAspect.timer(..)` 을 싱행하려 한다면

```xml
<!-- 기본적인 스키마 다운 -->
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:aop="http://www.springframework.org/schema/aop"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="
        http://www.springframework.org/schema/beans 
        http://www.springframework.org/schema/beans/spring-beans.xsd
        http://www.springframework.org/schema/aop 
        http://www.springframework.org/schema/aop/spring-aop.xsd">
        
        <!-- 빈 객체 등록하기 -->
        <!-- Controller Bean -->
        <bean id="sampleController" class="com.hurwan.controller.SampleController" />
        <!-- Aspect Bean -->
        <bean id="timerAspect" class="com.hurwan.aspect.TimerAspect" />
        
        <!-- AOP 설정 -->
        <aop:config>
	        <!-- Pointcut 정의 (실행 위치를 변수처럼 만들기) -->
	        <aop:pointcut id="timerSamplePointcut"
								        expression="execution(* com.hurwan.controller.SampleController.*(..))" />
					
					<!-- Aspect 정의 -->
					<!-- 넣을 로직이 정의 되어있는 객체 -->
					<aop:aspect ref="timerAspect">
						<!-- 설정할 메서드에 대해 Pointcut 설정해주기 -->
						<aop:around method="around" pointcut-ref="timerSamplePointcut" />
					
					</aop:aspect>
				</aop:config>
</beans>
					
```

와 같이 설정이 가능합니다.

## 사용방법 - 부트

스프링 부트에서는 프레임워크에 비해 매우 쉽게 설정이 가능하며

- `org.springframework.boot:spring-boot-starter-aop`
- 또는 4.x.x 버전 이후에는 `org.springframework.boot:spring-boot-starter-aspectj`

를 사용합니다.

### 의존성 종류

1. `org.springframework:spring-aop`
    
    스프링 AOP의 핵심 모듈로 Proxy 생성 로직, Advisor,  Advice, Pointcut 인터페이스, BeanPostProcessor, 동적 프록시 생성 (JDK Proxy, CGLIB 연동) 을 해주며 AOP 프록시 등의 관리를 해줍니다.
    
2. `org.aspectj:aspectjweaver` 
    
    Pointcut표현식 파싱(`execution`)과 AspectJ(중복제거 및 여러 기능 지원)기능을 지원합니다.
