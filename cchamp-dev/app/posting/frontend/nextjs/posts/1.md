# Next.js란 무엇인가

Next.js는 React 기반의 프레임워크로, 서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG)을 쉽게 사용할 수 있도록 도와준다.

단순한 React 앱과 달리, 라우팅과 데이터 패칭, SEO 최적화까지 포함된 구조를 제공한다.

---

## 왜 Next.js를 사용하는가

React만 사용할 경우 직접 해결해야 하는 것들이 많다.

- 라우팅 (React Router)
- SEO 문제
- 서버 사이드 렌더링
- 코드 분할

Next.js는 이런 문제를 기본적으로 해결해준다.

---

## App Router 구조

Next.js에서는 폴더 구조가 곧 라우팅이다.

예를 들어: 
```
app/
├─ page.tsx → /
├─ about/
│ └─ page.tsx → /about
├─ blog/
│ └─ [id]/
│ └─ page.tsx → /blog/1
```

이렇게 파일을 만들면 자동으로 URL이 생성된다.

## Server Component vs Client Component

Next.js에서는 기본이 Server Component이다.

### Server Component

- 서버에서 실행됨
- DB 접근 가능
- 보안에 유리
- `fs`, `process` 사용 가능
